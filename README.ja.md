# 🎃 Pumpkin Shift — ハロウィンの数字スライドパズル

**静かな屋敷で、数字のかぼちゃたちが場所を入れ替えました。** Pumpkin Shift は [2048 Online](https://2048online.top/) のために作られた、ハロウィンのスライドパズルです。数字を並べ直し、月明かりの力で少しだけ近道をして、12 の部屋と毎日のお題を楽しめます。おなじみの 8 パズルと 15 パズルに、各部屋 2 回の「ムーングライド」を加えました。

**[今すぐ遊ぶ](https://halloween-pumpkin-shift.crazy3d.org/)** · [ハロウィンゲーム集](https://github.com/AshinTop/halloween-games) · [埋め込みガイド](EMBEDDING.md) · [設計ノート](DESIGN.md)

**README の言語：** English、简体中文、Español、Português (Brasil)、日本語。**ゲーム内の表示は英語と簡体字中国語のみ**です。日本語などの README があっても、ゲームのメニューがその言語に対応しているわけではありません。

![数字タイル、空きマス、ムーングライドの残り回数が見える Pumpkin Shift のハロウィンパズル](docs/images/gameplay.jpg)

## 屋敷で見つかるもの 👻

- **全 12 部屋**。最初の 8 部屋は 3×3、最後の 4 部屋は 4×4 の盤面です。
- 各部屋 2 回のムーングライド。通常の移動は何度でもでき、取り消すと使った魔法も戻ります。
- UTC の日付で決まる、同じお題を共有できる 3×3 のデイリーパズル。
- 正しい位置の数字は緑色に。手数の目標、星、任意の効果音、オリジナルの屋敷の絵が進行を彩ります。
- 道順のヒント、部屋選択、ローカル保存に対応。制限時間はありません。

## 遊び方

数字を左から右、上から下へ小さい順に並べ、右下を空きマスにすると完成です。数字は空きマスへ移動するだけで、合体はしません。

空きマスの隣のタイルを押すと、通常の 1 手です。**ムーングライド**を使うには、空きマスと同じ行または列にある、離れたタイルを押します。その間のタイルがまとめて空きマス側へずれます。手数は 1 手、魔法は 1 回分を消費します。斜めには動かせません。

キーボードの矢印と画面の方向ボタンは、**空きマスの方向**を指定します。タイルはその反対へ動くので、特定の数字を動かしたいときは直接タップすると分かりやすくなります。

手数を超えても失敗にはならず、そのまま完成を目指せます。星は効率のよい解き方へのごほうびです。キャンペーンの目標には確認済みの解答ルートがあり、デイリーは最初のシャッフルを逆にたどれば魔法なしで目標に届きます。

## 操作

| 操作 | マウス・タッチ | キーボード |
|---|---|---|
| 隣の数字を動かす | タイルを押す | 矢印で空きマスを動かす |
| ムーングライド | 同じ行・列の離れたタイルを押す | タイルにフォーカスして実行 |
| 取り消す | 取り消しボタン | Z |
| 道順のヒント | ヒントボタン | Tab で選んで実行 |
| やり直し・部屋変更 | やり直し、選択欄、前後の部屋 | Tab と Enter |

**ヒントは安全な道順を示す機能で、最短手数の解答機ではありません。** 途中の寄り道を戻してから、初期シャッフルを逆にたどることがあります。ヒントを見るだけではタイルも手数も変わりません。

## デイリーと保存

盤面は完成形から合法な手順で混ぜているため、キャンペーンもデイリーも解けます。[部屋 9](https://halloween-pumpkin-shift.crazy3d.org/?level=9) から 4×4 に進みます。[今日のお題](https://halloween-pumpkin-shift.crazy3d.org/?mode=daily) は UTC 基準です。[日付入りリンク](https://halloween-pumpkin-shift.crazy3d.org/?mode=daily&date=2026-10-31) なら、その日の盤面を共有できます。

現在の盤面、最少手数、星、設定はブラウザーに保存します。リンクで別の盤面を指定していない場合、再読み込みで途中のゲームを復元できます。取り消し履歴は現在のセッション内だけです。

## よくある質問

**2048 と同じルールですか？** 数字のスライドパズルです。同じ数字を重ねて合体させることはありません。

**魔法を使い切ったら？** 通常の移動は続けられます。取り消しで魔法も戻り、やり直しで最初の盤面に戻せます。

**ヒントで後戻りするのはなぜ？** 既知の安全なルートを使うためです。毎回最短解の一手を示すわけではありません。

## ローカルで実行・確認する

```sh
python3 -m http.server 4173
```

リポジトリのルートでサーバーを起動し、[http://localhost:4173/](http://localhost:4173/) を開きます。静的なゲームなので、ビルドや依存パッケージのインストールは不要です。`file://` では ES モジュールが読み込めない場合があるため、HTTP(S) を使用してください。テストには Node.js が必要です。

```sh
npm test
```

**11 件のテスト**で、キャンペーンの解答と目標、デイリー生成、魔法の消費と使い切り、寄り道後のヒント、盤面の境界、日付リンク、保存データの検証を確認します。

ゲームのソースはアカウント、外部 API、広告 SDK、外部素材 CDN を必要としません。記録はブラウザー内に保存され、クラウド同期はありません。Cloudflare が独自のホスティング用スクリプトやリクエストログを追加する場合があります。任意の合成音声はブラウザーの再生許可に従います。
